# OpenBoxBridge 1.0.1

Bug fix for the UP Box+ release.

- **Fixed:** on Windows displays scaled above 100% (for example 150% or 175%), the Calibrate,
  Find bed centre and New spool windows were drawn at their small 100% size while their text was
  scaled up, so labels and buttons were cut off. They now scale with the display.

Nothing else has changed: same printer tools, presets and settings as 1.0.0.

**Download:** `OpenBoxBridge-1.0.1-windows.zip`. Unzip it and run `OpenBoxBridge.exe`. To update
from 1.0.0, replace `OpenBoxBridge.exe` with the new one; your settings and calibration are kept.
